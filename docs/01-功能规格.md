# 功能规格 · V3.0

> 做三件事：**任务登记与今日/本周查看**、**想法池**（捕获、整理、状态管理）、**日/周/月复盘**（人写、AI 只读）。当前状态：**已实现并验收**（2026-11-05）。
> V3.0 相对 V2.0 的变化：今日页底部新增**复盘区**（日 / 周 / 月）；复盘是独立数据域（三个单文件、可写窗口、材料只读、AI 只读）；任务与想法行为不变。
> 不扫描任何知识库或外部文档系统，不做固定动作规则、项目方向、周期任务（重复规则）、农历、提醒推送、AI 验收。
> 技术实现见 [02 实现架构](./02-实现架构.md)；整体图见 [03 整体架构图](./03-整体架构图.html)。

## 一、范围

**做**：

- 任务：今日视图、本周视图（自然周）、任务总表、任务详情；查看、创建、编辑、删除、完成/撤销完成。
- 任务类型：**当天任务**（某一天）、**跨周期任务**（开始日期 → 结束日期）；可选时间（小时:分钟）。
- 任务字段：四象限优先级、单行备注。
- 想法池：列表视图（状态统计 + 筛选 + 搜索 + 排序）、新建、编辑内容、改状态、删除。
- 想法字段：编号、名称、多行详细描述、状态（四态）、成熟度（三档，人工标记）、分类（可选）。
- **复盘**：日 / 周 / 月三类；今日页底部内联入口；窗口内提交 / 编辑 / 清空；周/月块内联上一周期材料；AI 只读。
- 复盘字段：周期键（日=日期 / 周=该周周一 / 月=`YYYY-MM`）、正文（多行纯文本，≤20000 字）、更新时间（自动）。
- 侧栏入口「任务工作台」（不做数字徽章）；面板内 4 个 tab：今日 / 本周 / 任务 / 想法（复盘在今日页底部）。
- AI 读任务 + 创建/编辑/删除任务；AI 读想法 + 新建/编辑内容/删除想法；**AI 只读复盘**（均走统一读写层，审计）。

**不做**：

- 扫描知识库 / 任何外部文档系统；不做 Daily。
- 固定运营动作规则、项目/方向列表、周期任务（按规则重复）。
- 农历、节假日/调休。
- 应用内提醒、系统通知、App/企微推送；想法「已放置 N 天」只是展示，不提醒；复盘块只在窗口内出现，不做「催办」。
- AI 认领/待验收/人工验收、AI 评估任务是否完成。
- **AI 写复盘**（无写工具；service 层拒绝非 user actor）。
- **复盘历史浏览 tab / 复盘统计图表 / 补写更早周期**（周只提示上一自然周，月只补次月 1–3 日）。
- **想法 → 任务转化**（下一版再评估）；想法看板视图；想法归档/容量上限/自动清理。
- 迁移/导入旧数据。
- 子任务、附件、多标签、多人协作、看板/甘特/日历事件。

> 边界理由：任务侧先把「记任务、看任务、勾完成」跑顺；想法侧先把「接住想法、标状态/成熟度、定期整理」跑顺；复盘侧只要「到点提示、人写、能回看 Markdown」，不做打卡与统计。三者共用一套写入/备份/审计，但数据文件与生命周期各自独立。

## 二、任务字段

| 字段 | 必填 | 取值 / 规则 | 默认 |
|---|---|---|---|
| 标题 | 是 | 文本，禁 `｜`、换行，≤200 字 | — |
| **任务类型** | 是 | 当天 / 跨周期 | 当天 |
| **日期** | 是 | `YYYY-MM-DD`；当天任务的任务日期，跨周期任务的开始日期 | 今天 |
| **时间** | 否 | `HH:mm`（24 小时制）；当天任务的执行时间，跨周期任务的开始时间 | 空 = 全天 |
| **结束日期** | 跨周期必填 | `YYYY-MM-DD`，必须晚于日期 | 空 = 当天任务 |
| **结束时间** | 否 | `HH:mm`；跨周期任务的结束时间，必须与结束日期同时出现 | 空 = 全天 |
| 优先级 | 否 | 重要紧急 / 重要不紧急 / 不重要紧急 / 不重要不紧急 | 重要不紧急 |
| 状态 | 是 | 待办 / 已完成（`[ ]` / `[x]`） | 待办 |
| 备注 | 否 | 单行文本，≤500 字 | 空 |
| 完成日期 | `[x]` 时必有 | `YYYY-MM-DD` | — |

- 任务类型的判定：有合法「结束日期」且晚于「日期」= 跨周期；否则 = 当天。
- 跨周期只支持一个连续区间；不做重复规则、不做项目/方向字段。
- **逾期**：未完成，且结束日期（当天任务用日期）< 今天；只读标记，不自动改日期。
- 不带时间 = 全天；排序时全天任务排在当天定时任务之前。

## 三、想法字段

| 字段 | 必填 | 取值 / 规则 | 默认 |
|---|---|---|---|
| 编号 | 是 | `I-YYYYMMDD-NN`，自动生成；删除后不复用 | — |
| 名称 | 是 | 文本，禁 `｜`/换行，≤200 字 | — |
| 详细描述 | 否 | 多行 Markdown 正文，≤10000 字；支持分段 | 空 |
| 状态 | 是 | 待实现 / 推进中 / 完成 / 放弃 | 待实现 |
| 成熟度 | 是 | 低 / 中 / 高（人工标记） | 低 |
| 分类 | 否 | 单行自由文本，禁 `｜`/换行，≤20 字（如 业务/学习/个人/产品/技术） | 空 |
| 创建日期 | 是 | `YYYY-MM-DD`，自动 | 今天 |
| 更新日期 | 是 | `YYYY-MM-DD`，编辑/改状态时自动 | 今天 |
| 完成日期 | 状态 = 完成时自动 | `YYYY-MM-DD`；离开「完成」时清除 | — |

- 成熟度定义：**低** = 只是个念头；**中** = 方向清楚，缺方案或验证；**高** = 方案清楚、可直接排期做。
- 状态四态互转；进入「完成」写完成日期，离开「完成」清除；「放弃」表示决定不做，不删除记录。
- **停滞提示**：未关闭（待实现/推进中）且距更新日期 ≥14 天，卡片显示「已放置 N 天」；只展示，不自动改状态。
- 想法是长期资产：**单文件、不按月切**；已完成/放弃的想法保留在文件里，靠筛选查看。

## 四、复盘字段与规则

| 字段 | 必填 | 取值 / 规则 | 默认 |
|---|---|---|---|
| 类型 | 是 | 日复盘 / 周复盘 / 月复盘 | — |
| 周期键 | 是 | 日=`YYYY-MM-DD`；周=该自然周**周一**（`YYYY-MM-DD`）；月=`YYYY-MM` | — |
| 正文 | 是 | 多行纯文本（保留换行与分段），≤20000 字；空白不可提交 | — |
| 更新时间 | 是 | 自动写 `YYYY-MM-DD HH:mm`（本地时区） | — |

**可写窗口（服务端强制）**

| 类型 | 出现 / 可写窗口 | 复盘对象 | 说明 |
|---|---|---|---|
| 日复盘 | 仅「今天」 | 今天 | 每天常驻一个输入框；只写今天，不补往天 |
| 周复盘 | 本周一 → 周日 | 上一个自然周（周一→周日） | 周一起整周显示；只提示上一个自然周，不累积更早的周 |
| 月复盘 | 当月最后一天 + 次月 1–3 日 | 当月（跨月补写时为上月） | 最后一天按实际 28/29/30/31；次月 1–3 日后不再提示 |

- 窗口外写入（含清空）→ `validation-error`，消息说明该周期已过可写窗口；UI 也不再显示入口。
- 复盘内容**只能由人写**：AI 没有写工具；service 层对非 user actor 返回 `permission-denied`。
- 三类都可原地编辑、清空（清空 = 硬删除该条 + 写前备份）；同一周期唯一，重复提交 = 更新。
- 复盘块**不提供隐藏/稍后再说**：窗口内一直显示（未写 = 输入框，已写 = 展示态）。

**材料（只读，周/月块内可折叠）**

- 周复盘材料：上一个自然周的任务概况（已完成 / 到期未完成，标题列表）+ 上周每一天的日复盘全文。
- 月复盘材料：本月任务概况（已完成 / 到期未完成）+ 本月的周复盘（含包含 1 号的那一周）。
- 跨月周/月**只读合并上月任务分片**（不触发月切、不写历史分片）；某分片无法解析时材料带 warning 并可能不完整（不静默降级）。

## 五、视图

### 5.1 今日

- **今天要做的**：未完成，且「日期 <= 今天 <= 结束日期」。
  - 当天任务：日期 == 今天。
  - 跨周期任务：今天在区间内就出现。优先级药丸紧跟任务名（标题行），剩余天数药丸放在 meta 行最前（区间文字之前）：`今天截止` / `明天截止` / `剩 N 天`（N = 结束日期 − 今天；≤1 天红色、2–3 天橙色、≥4 天品牌色）；之后才是「跨周期 11/5 → 11/9 · 第 X/Y 天」及可选时间。
- **逾期未完成**：结束日期 < 今天，标「逾期 N 天」（N 按结束日期算）。
- **今天已完成**：`完成 == 今天` 的任务（折叠区）。
- 排序：优先级（重要紧急 → 重要不紧急 → 不重要紧急 → 不重要不紧急）→ 全天在前 → 时间 → 文件行序。
- **复盘区**（今天已完成之后，顺序 日 → 周 → 月；周/月只在窗口内出现）：
  - 未写：类型徽标 + 相对周期文案（今天 · 周四 / 上周 · 10/26 – 11/1 / 本月 · 2026 年 11 月）+ 状态「待写」+（周/月）材料折叠 + 输入框 + 提交按钮（空内容禁用）。
  - 已写：徽标 + 周期 + 「已写 · 11/5 22:05 更新」+ 正文（保留换行）+ 编辑 / 清空。
  - 文件只读（格式损坏）：该块显示只读原因并禁用输入；任务视图与另外两类复盘不受影响。
- 侧栏入口「任务工作台」；不做数字徽章。

### 5.2 本周

- **自然周（周一至周日）**，含今天之前的列；今天高亮，之前淡显。
- 单日任务：按 `日期 == 当列` 落列。
- 跨周期任务：顶部显示为**一条摘要条**（一条任务一枚 chip：勾选 + 标题 + 起止日期 + 优先级色点 + 剩余天数药丸）；剩余天数与今日视图同一套算法与着色，已完成 chip 不显示；悬停/聚焦 chip 时对应的日期列高亮；点标题进入编辑。
- 摘要条上可直接勾选完成/撤销（仅人）。
- 跨周期任务只出现在摘要条，不重复进日期列；跨周任务显示真实起止日期。
- 不做拖拽改期；没有农历。

### 5.3 任务总表

- 默认显示全部未完成任务；可切换「含已完成」。
- 筛选：关键词（标题包含）、状态、优先级。
- 日期列显示：`今天 15:00`、`11/5 09:30 → 11/9 18:00` 等。
- 编辑/删除/完成入口在任务行或详情。

### 5.4 想法池

- 顶部状态统计条：**全部 / 待实现 / 推进中 / 完成 / 放弃**，显示计数，点击即筛选。
- 工具栏：搜索（名称 + 详细描述）、成熟度筛选、分类筛选、排序（状态优先 / 最近更新 / 最新创建 / 成熟度优先）、刷新。
- 默认排序：状态（待实现 → 推进中 → 完成 → 放弃）→ 更新日期倒序。
- 卡片：状态 pill（可直接点开改，仅人）、名称（点击进详情）、分类、描述最多两行、编号、成熟度三点、更新日期、「已放置 N 天」（≥14 天）、完成日期；完成/放弃卡片淡化；hover 出现编辑/删除。
- 新建/编辑弹窗：名称、详细描述（多行 textarea）、成熟度、分类；编辑弹窗另有状态分段（注明「状态只能由人修改」）、创建/更新/完成时间、删除入口。
- 空状态：无想法（提示首次创建会自动建文件）/ 无筛选结果（可清除筛选）。
- 文件只读时：显示只读横幅并禁用写控件，任务视图不受影响。

## 六、操作与规则

### 6.1 新建任务

- 入口：今日「新建」、本周「新建」、任务总表「新建」、AI 工具。
- 必填：标题、任务类型、日期（默认今天）。
- 当天任务：日期 + 可选时间。
- 跨周期任务：开始日期 + 可选开始时间 + 结束日期 + 可选结束时间；结束日期必须晚于开始日期。
- 可选：优先级、备注。
- 不经过 Inbox；创建后立即出现在对应视图。

### 6.2 编辑任务

- 可改：标题、任务类型、日期、时间、结束日期、结束时间、优先级、备注。
- 任务类型可互转：当天 → 跨周期补结束日期；跨周期 → 当天清空结束日期/结束时间。
- 改日期 = 改期；编辑后立即写回，失败提示，不假装成功。

### 6.3 删除任务

- **硬删除**：从清单移除该任务（不做归档/取消）。
- UI 删除需二次确认；写前自动备份（7 天）可用于恢复。
- AI 工具可删除（审计记录 actor/时间/前后值）。

### 6.4 完成 / 撤销完成（任务）

- 勾选完成：`[ ]` → `[x]`，写完成日期；跨周期任务的区间/时间字段原样保留。
- 可撤销：回到待办，删除完成日期。
- **完成只能由人确认**；AI 不能完成/撤销完成（返回权限错误）。

### 6.5 查看（任务）

- 今日/本周/总表/详情只读接口，人与 AI 都可读。

### 6.6 新建想法

- 入口：想法 tab 页头「新建想法」、空状态按钮、AI 工具。
- 必填：名称；可选：详细描述、成熟度（默认低）、分类。
- 状态固定默认「待实现」，创建时不选状态。
- 创建后立即出现在列表；想法文件不存在时自动创建。

### 6.7 编辑想法

- 可改：名称、详细描述、成熟度、分类、状态。
- 详细描述支持多行/分段；空字符串表示清空。
- 保存后更新「更新日期」；没有实际变化时不发写请求。

### 6.8 改想法状态

- 四态互转：待实现 / 推进中 / 完成 / 放弃。
- **状态只能由人改**：卡片 pill 下拉、编辑弹窗状态分段；AI 没有改状态工具，越权返回 `permission-denied`。
- 进入「完成」自动写完成日期；离开「完成」清除完成日期。

### 6.9 删除想法

- **硬删除**：从想法池移除（不删除文件）。
- UI 需二次确认；写前自动备份（7 天）可用于恢复。
- AI 工具可删除（审计记录 actor/时间/前后值）；删除前应复述名称。

### 6.10 提交 / 编辑 / 清空复盘

- 入口：今日页底部复盘区（周/月块仅在窗口内出现）。
- 提交：正文去首尾空行后必须非空、≤20000 字；成功后就地变「已写 · 更新时间」；同一周期再提交 = 更新。
- 编辑：已写块点「编辑」→ 弹出输入框（预填正文）→ 保存 / 取消；保存同样走窗口校验。
- 清空：二次确认（说明写前备份）→ 移除该条 → 回到「待写」。
- 失败处理：窗口外 → 提示已过可写窗口；文件外部修改 → `external-change` 阻止覆盖并自动重载；文件损坏 → 该类型只读并显示原因；不假装成功。
- **AI 不能提交/编辑/清空复盘**（无工具；service 兜底拒绝）。

## 七、AI 行为

- AI 与面板共用统一读写层：任务走 `TaskService`（`tw_*`），想法走 `IdeaService`（`tw_idea_*`），复盘走 `ReviewService`（`tw_review_*` **只读**）；不存在第二套接口。
- 任务 AI 可：读取今日/本周/任务/详情；创建任务（当天或跨周期）；编辑任务；删除任务。
- 任务 AI 不可：完成/撤销完成、改设置、扫知识库、生成 Daily。
- 想法 AI 可：读取列表/详情；新建想法；编辑名称/描述/成熟度/分类；删除想法。
- 想法 AI 不可：改状态（待实现/推进中/完成/放弃）；改设置；直接改 Markdown。
- 复盘 AI 可：`tw_review_list`（按类型与周期范围列出，返回摘要）、`tw_review_get`（读取某条完整正文）。
- 复盘 AI 不可：创建 / 修改 / 删除复盘；改设置；直接改复盘 Markdown。越权返回 `permission-denied`。
- 所有 AI 写入带 actor 审计（谁、何时、哪个工具、前后值）；失败返回结构化错误，不假装成功。
- 插件随包提供 `task-workbench` 技能，指导 AI 使用三套工具；技能不改变上面的权限边界。

## 八、数据与保留

- 数据真源（默认数据根 `$DSH_HOME/task-workbench/data`；不进 Git）：
  - 任务：`data/任务清单/YYYY-MM.md`，按月分片，当月唯一可写、历史只读；
  - 想法：`data/想法池/想法池.md`，单文件、长期保留、不按月切；
  - 复盘：`data/复盘/日复盘.md`、`周复盘.md`、`月复盘.md`，三个单文件、长期保留、不按月切。
- 写前备份：`data/备份/<YYYY-MM-DD>/`（任务 `任务清单-*`、想法 `想法池-*`、复盘 `日复盘-*` / `周复盘-*` / `月复盘-*`），默认保留 7 天（`settings.backupRetentionDays` 可设 1–90）。
- 不做旧数据迁移/导入；任务从当月分片开始，想法从空池开始，复盘从空文件开始（首次提交自动建文件）。

## 九、验收（V3.0，已执行）

**任务 / 想法回归**

**复盘**

2. 重载插件后 `/tw/api/health` 返回 `version: 0.3.0`；`GET /tw/api/reviews` 返回当日提示（日复盘 + 上一自然周周复盘），hash/只读/材料字段完整。
3. 真实 GUI：今日页底部出现复盘区；日复盘输入 → 提交 → 自动创建 `data/复盘/日复盘.md`（frontmatter + `## 记录` + `周期键｜更新` + 2 空格缩进正文、空行分段）；写前备份 `日复盘-<HHMMSS>.md` 存在；审计 `review-create`、`actor=user`。
4. 周复盘提交写回 `周复盘.md`（键 = 周一）；块内「上周材料」显示完成/未完成计数与日复盘条数；审计正确。
5. 编辑已写复盘 → 同一周期原地更新（不新增条目）、更新时间刷新、审计 `review-update`、写前备份存在。
6. 清空 → 二次确认弹窗 → 该条移除、文件回到骨架、审计 `review-delete`、备份存在；另一类型复盘不受影响。
7. 窗口外写入（补昨天 / 写成这周 / 月中写月复盘）→ 400 `validation-error`；AI actor 写入 → 403 `permission-denied`。
8. 月末口径（用临时数据根 + 注入时间做单测覆盖）：28/30/31 天月末均出现月复盘；次月 1–3 日可补写，4 日起不再出现；跨年 1 月 1–3 日补写上一年 12 月。
9. 材料跨月：上周 10/26–11/1 的完成/未完成任务由 10 月与 11 月分片合并统计；读取过程不改动历史分片（逐字节一致）。
10. AI 只读工具（真实数据根）：`tw_review_list` / `tw_review_get` 返回正确；AI 写复盘被 `permission-denied` 拒绝；审计无 AI 复盘写入记录。
11. 文件损坏隔离：日复盘文件损坏时该块只读、周复盘仍可正常读写。
12. 验收后清理：删除测试复盘文件与复盘备份，`writes.log` 还原；`data/任务清单/2026-11.md` 与 `data/想法池/想法池.md` 与验收前**逐字节一致**。
