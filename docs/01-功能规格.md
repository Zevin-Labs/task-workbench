# 01 · 功能规格

> 当前产品范围是任务按日/周查看、任务列表、想法池，以及日/周/月复盘。已发布的 0.5.0 使用 Markdown；当前实现改用 SQLite，产品日期口径、权限和字段含义不变。
> 实现与存储契约见 [02 实现架构](./02-实现架构.md)。

## 一、范围

**任务**

- 今日、本周（周一至周日）、任务总表和详情。
- 本周页底部：本周/本月概览（环形完成率 + 总数/已完成/进行中/逾期）与只读月历（周一至周日、相邻月补位、可前后翻月、点日期查看当天任务并可在当天新建/编辑任务）。
- 当天任务或跨周期任务；日期可以带可选时间。
- 查看、创建、编辑、删除、完成、撤销完成。
- 四象限优先级、可选单行备注。

**想法池**

- 列表、状态筛选、搜索、成熟度/分类筛选和排序。
- 创建、编辑内容、改状态、删除。
- 四种状态、三档成熟度、多行描述和可选分类。

**复盘**

- 日、周、月三类；今日页底部入口。
- 可写窗口内提交、编辑、清空；周/月包含周期材料。
- 今日页复盘区提供简单的周期回查入口，历史复盘只读；不增加独立历史 tab。
- AI 可查复盘，正文只由人写。

**不做**

- 扫描或依赖知识库、Daily、外部笔记；不导入旧版 Markdown。
- 固定动作规则、项目方向、重复任务、农历、系统提醒或推送。
- AI 判断任务完成、AI 写复盘、AI 认领或审核任务。
- 想法转任务、看板、自动归档、复盘统计图表、更早周期补写。
- 任务总表不提供按月份浏览历史任务；本周页月历只做只读翻月、按日期查看当天任务（可进编辑）与当天新建入口，不提供整月历史任务列表。
- 日历时间块匹配与人与 AI 协作执行流程。本阶段只保留稳定业务 ID 和领域 Service 作为以后扩展的入口，不预建字段、表或工具。

## 二、任务字段与规则

| 字段 | 必填 | 规则 | 默认 |
|---|---|---|---|
| ID | 是 | 稳定递增序号，例如 T-1；删除后不复用 | 自动生成 |
| 标题 | 是 | 单行文本，最多 200 字；允许全角分隔符「｜」 | — |
| 日期 | 是 | YYYY-MM-DD；当天任务日期或跨周期开始日期 | 今天 |
| 时间 | 否 | 24 小时制 HH:mm；不填表示全天 | 空 |
| 结束日期 | 跨周期必填 | YYYY-MM-DD，必须晚于开始日期 | 当天任务为空 |
| 结束时间 | 否 | HH:mm；只能和结束日期一起使用 | 空 |
| 优先级 | 否 | 重要紧急 / 重要不紧急 / 不重要紧急 / 不重要不紧急 | 重要不紧急 |
| 状态 | 是 | 待办 / 已完成 | 待办 |
| 备注 | 否 | 单行文本，最多 500 字 | 空 |
| 完成日期 | 已完成时 | YYYY-MM-DD | 自动生成 |

- 有结束日期表示跨周期任务，否则是当天任务；日期区间为连续区间，不支持重复规则。
- 未完成且结束日期（当天任务用日期）早于今天时显示逾期，不自动改日期。
- 今日视图包含今天处于区间内的未完成任务；本周视图按自然周显示单日任务，并把跨周期任务按轨道贯穿画进 7 个日卡（截止日落在日卡里的截止卡上）。
- 总表默认显示全部未完成任务；切换“含已完成”时包含本月完成的任务。未完成任务跨月仍保留为同一条记录，不复制到新月份。已完成任务跨月后只读。
- 完成/撤销只能由人确认；AI 没有对应工具。

## 三、想法字段与规则

| 字段 | 必填 | 规则 | 默认 |
|---|---|---|---|
| ID | 是 | 稳定递增序号，例如 I-1；删除后不复用 | 自动生成 |
| 名称 | 是 | 单行文本，最多 200 字；允许全角分隔符「｜」 | — |
| 详细描述 | 否 | 多行文本，最多 10000 字 | 空 |
| 状态 | 是 | 待实现 / 推进中 / 完成 / 放弃 | 待实现 |
| 成熟度 | 是 | 低 / 中 / 高 | 低 |
| 分类 | 否 | 单行自由文本，最多 20 字 | 空 |
| 创建日期 | 是 | YYYY-MM-DD | 自动 |
| 更新日期 | 是 | YYYY-MM-DD，修改内容或状态时更新 | 自动 |
| 完成日期 | 状态为完成时 | YYYY-MM-DD；离开完成状态时清除 | 自动 |

- 成熟度由人标记：低=只是念头；中=方向清楚但需验证；高=方案已清楚、可排期。
- 未关闭的想法超过 14 天未更新时显示“已放置 N 天”；不自动改状态或提醒。
- 状态只能由人改。AI 可以读取、创建、编辑想法内容和删除，但不能改状态。

## 四、复盘字段与周期

| 字段 | 规则 |
|---|---|
| 类型 | daily / weekly / monthly |
| 周期键 | 日=YYYY-MM-DD；周=该自然周周一；月=YYYY-MM |
| 正文 | 多行纯文本，最多 20000 字，空白内容不可提交 |
| 更新时间 | 本地时间 YYYY-MM-DD HH:mm，自动更新 |

**可写窗口由服务端校验**

| 类型 | 可写窗口 | 复盘对象 |
|---|---|---|
| 日复盘 | 仅当天 | 今天 |
| 周复盘 | 周一至周日 | 上一个自然周 |
| 月复盘 | 当月最后一天至次月 3 日 | 本月；次月补写时为上月 |

- 窗口外的复盘只读；不能补写更早周期。
- 清空复盘会硬删除该条记录；清空与硬删除任务/想法前生成并校验数据库快照。
- AI 只能用 tw_review_list 和 tw_review_get。没有创建 / 修改 / 删除复盘工具；服务端也拒绝 AI 写入。

**材料**

- 周复盘材料：上一个自然周完成的任务、该周到期未完成的任务、该周日复盘。
- 月复盘材料：本月任务概况与本月周复盘。
- 任务、复盘都从同一数据库按日期查询；跨月直接覆盖日期范围，不拼接文件。

## 五、视图

### 5.1 今日

- 显示逾期未完成、今天要做、今天已完成。
- 跨周期任务处于日期区间时显示在今日视图。
- 页面底部按日、周、月顺序显示当前可写窗口内的复盘。
- 复盘区提供周期回查入口；已过窗口的历史复盘可只读查看，不允许编辑。

### 5.2 本周

- 自然周按周一至周日显示 7 个日卡，今天高亮。
- 跨周期任务按轨道贯穿整周：轨道从上往下排，顺序为「截止日越晚越靠上 → 重要度 → 开始日 → 开始时间 → 创建顺序」，因此仍在进行中的任务占据顶部连续轨道，每格顶部只按当天最大轨道号留高度，不留空行。
- 每个日卡自上而下：先排「截止卡」（跨周期任务在本周的落点：本周截止 = 截止日；延续到下周 = 周日），再排当天自己的任务。
- 走线：跨周期任务在覆盖的每一天画一条同色线（一条任务一个颜色），线在最上层；上周就已开始的从日卡左边界外以虚线进入，本周内开始的从当天日卡的水平中线起头；线尾被截止卡盖住，停在卡片正中。
- 卡片语言：跨周期卡为白底 + 任务色左竖条 + 角旗（红=今天截止或已逾期，橙=还剩 1–2 天）；当日任务用底色表达四象限优先级（重要紧急红 / 重要不紧急橙 / 不重要紧急蓝 / 不重要不紧急灰），不再写优先级文字。
- 可在人机权限允许的范围内完成/撤销任务；不支持拖拽改期。
- 页面底部为两列概览 + 一列月历：
  - 本周概览与本月概览结构一致：三段环（已完成/进行中/逾期）+ 总任务、已完成、进行中、逾期四个数字；本周卡固定当前自然周，本月卡跟随月历当前月份。
  - 口径：总任务 = 日期区间与该周期相交的任务（跨周期按区间相交、去重）；已完成 + 进行中 + 逾期 = 总数；进行中 = 未完成且截止日不早于今天。
  - 月历固定 6 行（周一至周日），前后用相邻月份日期补位；今天用深色圆底标注；不画跨周期区间线：单日任务与跨周期截止日在数字下方各落一个任务点（红=有未完成，灰=当天相关任务全部完成），跨周期任务只在截止日出现。
  - 月历可前后翻月（跨年自动），「今天」回到当前月；点击日期打开当天任务详情弹窗（当天单日任务 + 覆盖当天的跨周期任务，含时间、优先级、区间与备注；没有任务显示“没有任务”），弹窗里点任务进入编辑、可勾选完成，并可在该日期新建任务；相邻月份的日期格不显示任务标记，点击会先翻到所属月份再打开详情。

### 5.3 任务总表

- 默认显示所有未完成任务；含已完成切换仅补充本月完成记录。
- 可按关键词、状态和优先级筛选。
- 跨月未完成任务仍显示同一个 ID 和记录；过月已完成记录只读。
- 不提供按月份浏览历史任务的独立界面。

### 5.4 想法池

- 状态统计和筛选；可按名称/描述搜索，按成熟度、分类和排序方式筛选。
- 卡片展示状态、名称、分类、描述摘要、ID、成熟度与日期。
- 状态只能由人在卡片或编辑界面修改；AI 不提供改状态工具。

### 5.5 复盘回查

- 从今日页复盘区进入，按周期查阅复盘记录。
- 历史正文只读，写入仍受日/周/月窗口限制。
- 不做独立复盘 tab、统计或趋势分析。

## 六、操作与权限

| 操作 | 人 | AI |
|---|---|---|
| 读任务 | 是 | 是 |
| 创建/编辑/删除任务 | 是 | 是 |
| 完成/撤销任务 | 是 | 否 |
| 读想法 | 是 | 是 |
| 创建/编辑内容/删除想法 | 是 | 是 |
| 改想法状态 | 是 | 否 |
| 读复盘 | 是 | 是，只读 |
| 创建/编辑/清空复盘 | 是，限可写窗口 | 否 |

所有 UI 和 AI 操作都调用领域 Service。AI 工具仍为 14 个：任务 7 个、想法 5 个、复盘只读 2 个。拒绝或失败必须返回明确错误，不能表述为已完成。

## 七、数据初始化

- 唯一数据文件是 dataRoot/workbench.sqlite；默认 dataRoot 为 DSH_HOME/task-workbench/data，可由 settings.json 的 dataRoot 覆盖。
- 初始化创建空数据库；不会导入或转换旧版 Markdown。0.5.0 是历史 Markdown 版本；其测试数据已私下归档，不是当前数据库的来源。
- 任务、想法用稳定递增序号；复盘以类型和周期键唯一标识。
- 硬删除/清空前写入并校验 SQLite 快照。备份保留天数由 backupRetentionDays 控制，默认 7 天、可设 1–90 天。
