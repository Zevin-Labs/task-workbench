02

功能地图

V3.0 的能力范围；任务 / 想法 / 复盘三个域，每张卡都已实现并在真实界面验收。

Features

今日

Today V1.1 已实现

今天要看的任务：进行中的、逾期的、今天完成的。

  • 今天要做未完成且 开始日期 <= 今天 <= 结束日期；跨周期任务在区间内每天出现
  • 跨周期显示「跨周期 11/5 → 11/9 · 第 X/Y 天」与可选开始/结束时间
  • 逾期结束日期 < 今天，标「逾期 N 天」（只读标记，不自动改日期）
  • 今天已完成折叠区：完成 == 今天 的任务
  • 排序优先级 → 全天在前 → 时间 → 文件行序；入口侧栏「任务管理」

本周

Week V1.1 已实现

自然周（周一至周日），7 列；单日任务落列，跨周期任务收在顶部摘要条。

  • 7 列日卡每列放 日期 == 当列 的当天任务
  • 跨周期摘要条一条任务一枚 chip（标题 + 起止日期 + 优先级色点），悬停高亮对应日期列，可直接勾完成
  • 今天高亮今天之前的列淡显
  • 不做拖拽改期、农历、节假日

任务总表

All Tasks V1.1 已实现

所有任务的平铺列表，用来搜索、筛选和批量处理。

  • 默认显示全部未完成任务
  • 含已完成可切换显示已完成任务
  • 筛选关键词（标题包含）/ 状态 / 优先级；日期列显示时间或区间
  • 行内操作编辑 / 删除 / 完成

想法池

Idea Pool V2.0 新增

零摩擦接住想法，再用状态与成熟度整理；状态由人维护，AI 只读写内容。

  • 字段编号 I-YYYYMMDD-NN / 名称 / 多行详细描述 / 状态四态 / 成熟度三档 / 分类（可选）
  • 四态待实现 → 推进中 → 完成 / 放弃；完成自动写完成日期，放弃保留记录
  • 成熟度低（念头）/ 中（方向清楚）/ 高（可直接排期）；人工标记，不做 1–5 分
  • 列表状态统计可点击筛选 + 搜索名称/描述 + 成熟度/分类筛选 + 排序；卡片可直接改状态，≥14 天未动显示「已放置 N 天」
  • 存储data/想法池/想法池.md 单文件、不按月切；首次创建自动建文件；写前备份
  • AI读列表/详情、新建、编辑内容、删除；没有改状态工具

复盘

Daily / Weekly / Monthly Review V3.0 新增

到点提示、人写、AI 只读；写完留在 Markdown 里，不做打卡与统计。

  • 位置今日页「今天已完成」之后，顺序 日 → 周 → 月；周/月块只在窗口内出现
  • 日复盘每天一条，只写今天；提交后原地展示，可编辑 / 清空
  • 周复盘本周一 → 周日出现，复盘上一个自然周；不累积更早的周；材料 = 上周任务概况 + 上周日复盘
  • 月复盘当月最后一天（28/29/30/31 按实际）出现，复盘本月；次月 1–3 日可补写；材料 = 本月任务概况 + 本月周复盘
  • 可写窗口日=今天 / 周=本周 / 月=月末→次月 3 日；服务端强制，窗口外只读
  • 存储data/复盘/日复盘.md、周复盘.md、月复盘.md 三个单文件、不按月切；无 ID（周期键唯一）；写前备份
  • AI只读：ptw_review_list / ptw_review_get；没有写工具，正文只能由人写

操作

Actions V1.1 已实现

五个动作，没有 Inbox，也没有归档。

  • 新建当天（日期，可带 HH:mm）或跨周期（开始 → 结束，可带开始/结束时间）；不过 Inbox
  • 编辑标题 / 类型 / 日期 / 时间 / 结束日期 / 结束时间 / 优先级 / 备注；跨周期与当天可互转
  • 删除硬删除；二次确认 + 写前备份
  • 完成 · 撤销仅人；写完成日期，撤销后回到待办

AI

Agent V1.1 已实现

AI 是受限写入者：能读、能建改删任务与想法内容，但不能替人完成或改想法状态。

  • 任务读 4 工具ptw_today / ptw_week / ptw_list / ptw_get_task
  • 任务写 3 工具ptw_create / ptw_update / ptw_delete
  • 想法读 2 工具ptw_idea_list / ptw_idea_get
  • 想法写 3 工具ptw_idea_create / ptw_idea_update / ptw_idea_delete
  • 复盘只读 2 工具ptw_review_list / ptw_review_get（没有写工具）
  • 人工闸门任务完成 / 撤销、想法改状态、复盘正文都只能由人；AI 没有对应工具，越权返回 permission-denied
  • 审计每次 AI 写记 actor / 工具 / 前后值 / 时间

设置

Settings V1.1 已实现

只放必要配置，不碰任务数据。

  • 数据目录data/ 路径与当月分片位置
  • 备份保留 7 天，位置 data/备份/
  • 主题B 纸张（默认）/ C 夜色

任务一个月一个分片，当月唯一可写；想法与复盘单文件长期保留，不按月切。

Data Model

想法 · 单文件长期保留
data/想法池/想法池.md
## 想法每个想法 = 元数据行（状态/成熟度/分类/创建/更新/完成）+ 2 空格缩进的多行描述；块间空行分隔

不按月切；文件不存在时首次创建自动生成；写前自动备份。

复盘 · 三个单文件长期保留
data/复盘/日复盘.md · 周复盘.md · 月复盘.md
## 记录每条复盘 = 周期键行（2026-11-05 / 2026-11-02 / 2026-11）+ 2 空格缩进正文；空行分段

不按月切；首次提交自动建文件；可写窗口外只读；周/月材料只读合并相邻月任务分片。

历史 · 只读
2026-10.md · 2026-09.md …

历史任务分片：同结构；默认不加载，按需只读，不迁移、不改写。

备份
data/备份/YYYY-MM-DD/

每次写入前快照（任务清单-* / 想法池-* / 日复盘-* / 周复盘-* / 月复盘-*）；保留 7 天；恢复时手动复制回目标文件。

任务月切 当月分片不存在 → 新建（月切） · 只把 未完成任务 搬过去 · 已完成记录留在原月份（只读）

为什么这样分：任务有「月生命周期」，活跃清单只装没做完的事，完成记录按月留在各自分片；想法与复盘是长期资产，放进月分片会被月切破坏，所以单文件保存（复盘按类型分三个文件、互不影响）。历史任务默认不加载，打开即快。

「三个域，各一条写路径；同一套写入纪律」

任务 / 想法 / 复盘各自只有一个 service：同一队列、同一把 baseHash 锁、同一份备份与回读——域内没有第二套接口。

05

边界

V3.0 只做任务管理 + 想法池 + 复盘；范围外的事明确不做。

Boundaries

做In scope

  • 任务登记与管理：今日 / 本周 / 任务总表 / 设置
  • 查看、创建、编辑、删除、完成 / 撤销
  • 当天 / 跨周期任务 + 可选时间 + 四象限优先级 + 备注
  • 想法池：列表 / 筛选 / 搜索、新建、编辑内容、改状态、删除、四态 + 三档成熟度 + 多行描述
  • 复盘：日 / 周 / 月三类，窗口内提交 / 编辑 / 清空，周 / 月材料内联，AI 只读
  • AI 读任务 + 创建 / 编辑 / 删除任务；读想法 + 新建 / 编辑内容 / 删除想法；只读复盘（各自 service，带审计）
  • 侧栏「任务管理」入口（不做数字徽章）

不做Out of scope

  • 不扫知识库；不生成、不依赖外部 Daily 系统
  • 固定动作规则 / 项目方向 / 周期任务（重复规则）
  • 复盘历史浏览 tab / 复盘统计图表 / 补写更早周期（周只提示上一自然周，月只补次月 1–3 日）
  • AI 写复盘（没有写工具，service 兜底拒绝）
  • 农历、节假日；工作台内提醒、系统推送
  • AI 认领 / 待验收 / 人工验收；AI 判断任务是否完成或改想法状态
  • 想法 → 任务转化、想法看板、自动归档 / 容量上限
  • 迁移 / 导入旧数据；子任务 / 附件 / 标签 / 多人协作

V3.0 的取舍：任务侧先把「记任务、看任务、勾完成」跑顺；想法侧先把「接住想法、标状态/成熟度、定期整理」跑顺；复盘侧只要「到点提示、人写、能回看 Markdown」，不做打卡与统计。三个域共用写入纪律，但数据文件与生命周期分开；转化、看板、提醒、复盘历史等能力以后需要时再加。
