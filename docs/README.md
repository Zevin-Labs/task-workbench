# 文档索引 · V3.0

> 当前状态：**V3.0 已实现、已安装、已真实 GUI 验收**（2026-11-05）；**2026-11-06 已开源到 GitHub（`Zevin-Labs/task-workbench`）；当前版本 `0.5.0`（改名 + 工具前缀改为 `tw_*`），npm 发布与 `v0.5.0` Release 待执行**。
> 仓库：https://github.com/Zevin-Labs/task-workbench · npm：`dsh-task-workbench`（待发布） · Release：v0.3.0（历史，含 tgz）。
> V3.0 变化：今日页底部新增**复盘区**（日 / 周 / 月，人写、AI 只读）；新增独立复盘数据域——`ReviewService` 唯一写网关、`/tw/api/reviews*` 路由、`tw_review_list` / `tw_review_get` 只读 AI 工具。
> 数据真源：`data/任务清单/YYYY-MM.md`（任务，按月分片）+ `data/想法池/想法池.md`（想法，单文件长期保留）+ `data/复盘/{日,周,月}复盘.md`（复盘，三个单文件、不按月切）；默认数据根 `$DSH_HOME/task-workbench/data`；均不进 Git。
> 不扫描任何知识库或外部 Daily 系统，不导入旧数据。

## 现在能做什么

**任务（V1.1 能力保持不变）**

- 侧栏「任务工作台」打开面板：**今日 / 本周 / 任务**三个视图。
- 新建任务：当天（日期 + 可选时间）或跨周期（开始 → 结束，结束必须晚于开始，可选开始/结束时间）；四象限优先级、单行备注；创建后立即写回 Markdown。
- 今日视图：优先级药丸紧跟任务名（标题行），跨周期任务在 meta 行最前显示剩余天数药丸（今天截止 / 明天截止 / 剩 N 天，按紧迫度着色），其后是区间进度与时间；本周视图顶部一条跨周期摘要条，chip 上同样显示剩余天数（悬停 chip 高亮对应日期列）；任务表显示日期/时间/区间。
- 编辑（跨周期 ↔ 当天互转、可清空时间）、删除（硬删除，二次确认 + 写前备份）、完成 / 撤销完成（勾选即写回）。
- 外部编辑当月分片：每 5 秒轮询发现后自动重载；写入前用 `baseHash` 防止覆盖外部修改。
- AI 通过 `tw_*` 工具读任务、创建/编辑/删除任务；**没有完成工具**，完成/撤销只能由人。

**想法池（V2.0 能力保持不变）**

- 面板第 4 个 tab「想法」：状态统计条（全部 / 待实现 / 推进中 / 完成 / 放弃，点击即筛选）+ 工具栏（搜索名称/描述、成熟度、分类、排序、刷新）+ 卡片列表。
- 新建想法：名称必填；多行详细描述、成熟度（低/中/高，默认低）、分类（可选）；状态默认「待实现」。
- 卡片上可直接改状态（仅人）；标题进详情/编辑弹窗；未关闭且 ≥14 天没动显示「已放置 N 天」；完成/放弃卡片淡化；硬删除有二次确认 + 写前备份。
- 数据写回 `data/想法池/想法池.md`（单文件、不按月切）；文件不存在时，首次创建想法自动生成。
- AI 通过 `tw_idea_*` 工具读想法、新建、编辑内容（名称/描述/成熟度/分类）、删除；**没有改状态工具**，状态只能由人改。

**复盘（V3.0 新增）**

- 今日页「今天已完成」之后是**复盘区**：`日复盘` → `周复盘`（窗口内）→ `月复盘`（窗口内）。
- **日复盘**：每天一条，写今天；提交后原地展示正文 + 更新时间，可编辑 / 清空。
- **周复盘**：本周一 → 周日出现，复盘**上一个自然周**（周一→周日），不累积更早的周；块内「上周材料」可展开——上周完成/到期未完成的任务（跨月周合并读取上月分片）+ 上周每天的日复盘。
- **月复盘**：**当月最后一天**（28/29/30/31 按实际）出现，复盘本月；**次月 1–3 日**仍可补写；材料含本月任务概况 + 本月周复盘。
- **可写窗口**：日=今天；周=本周（上周那个周期键）；月=月末最后一天→次月 3 日。服务端强制校验，窗口外写入返回 `validation-error`；过了窗口的复盘只读，历史内容只能在 Markdown 里改。
- **仅人写**：AI 只有 `tw_review_list` / `tw_review_get` 只读工具；没有复盘写工具，service 层对非 user actor 也直接 `permission-denied`。
- 三个复盘文件互相独立：某个文件格式损坏只影响该类型的显示与写入，任务/想法/其他复盘类型不受影响。
- 数据写回 `data/复盘/{日,周,月}复盘.md`；文件不存在时首次提交自动生成；写前备份进 `data/备份/<日期>/`。

## 已定决策（不再反复）

**任务**

1. **数据位置**：默认数据根 `$DSH_HOME/task-workbench/data`，文件名 `任务清单/YYYY-MM.md`；不依赖任何外部笔记/Daily 系统。
2. **按月分片**：当月唯一可写，历史只读；不做周文件；周视图是查询。
3. **优先级**：四象限单字段；**没有「每日核心」**；今日默认重要紧急在前。
4. **任务类型**：当天（单日）与跨周期（连续开始→结束区间）；不做重复规则/项目方向。
5. **时间**：可选 `HH:mm`；不填 = 全天；跨周期可带开始/结束时间，结束时间必须有结束日期。
6. **删除**：硬删除（二次确认 + 写前备份），不做归档/取消/回收站。
7. **AI**：可直接读 + 创建/编辑/删除（统一 TaskService、审计）；完成/撤销仅人。
8. **本周**：自然周（周一至周日），含今天之前；跨周期任务统一收在顶部一条摘要条里，悬停 chip 高亮对应日期列。
9. **AI 评估完成**：不做；任务是否完成由人反馈。

**想法池**

10. **独立数据文件**：`data/想法池/想法池.md`，**单文件、不按月切**；想法是长期资产，不放进任务月分片。
11. **四态**：待实现 / 推进中 / 完成 / 放弃；不加「待评估 / 已归档」等中间态；完成写完成日期，离开完成清除。
12. **成熟度**：三档 低 / 中 / 高，人工标记；不做 1–5 分（评分通胀）。
13. **状态仅人**：AI 可读/新建/编辑内容/删除，但没有改状态工具；越权返回 `permission-denied`。
14. **详细描述**：多行 Markdown 正文（想法行下 2 空格缩进续行，空行分段），不压成单行。
15. **分类**：可选单行自由文本（≤20 字），不做固定枚举/多标签。
16. **主视图**：列表 + 状态筛选（不做看板）；默认排序 状态优先 → 更新日期倒序。
17. **想法 → 任务转化**：V2.0 不做，下一版再评估（需要跨模块关联与回写语义）。

**复盘**

18. **位置与形态**：不做独立「复盘」tab；复盘块内联在**今日页底部**（今天已完成之后），顺序 日 → 周 → 月；周/月块内联带出上一周期材料，历史回看以打开 Markdown 为主。
19. **周复盘窗口**：周一起**整周显示**，只复盘**上一个自然周**（周一→周日），不累积更早的周；写完变展示态（可编辑/清空）。
20. **月复盘口径**：**当月最后一天**出现（按实际 28/29/30/31，不用固定 31 号），复盘**本月**；**次月 1–3 日**仍可补写，之后不再提示。
21. **修改与补写**：三类都可在窗口内原地编辑 + 清空（二次确认 + 写前备份）；日复盘只写今天，不补往天；周/月按窗口补写。
22. **AI 权限**：**AI 可读复盘**（`tw_review_list` / `tw_review_get`），**绝不能写**；无写工具，service 层对非 user actor 兜底拒绝。
23. **数据文件**：`data/复盘/日复盘.md`、`周复盘.md`、`月复盘.md` 三个单文件、不按月切；键是天然周期键（日=日期、周=该周周一、月=`YYYY-MM`），**不需要 ID**。
24. **复盘块格式**：`## 记录` 下 `- \`周期键\`｜更新：YYYY-MM-DD HH:mm` + 2 空格缩进正文（可含 `｜`/`#`/`- `，不会被误解析）；纯文本保留换行，不接 Markdown 渲染；正文上限 20000 字、空内容不许提交。
25. **材料只读**：周块材料 = 上周任务概况（完成 / 到期未完成，标题列表）+ 上周日复盘；月块材料 = 本月任务概况 + 本月周复盘；跨月周/月**只读合并上月分片**（不触发月切）；某分片损坏时材料带 warning，不静默降级。
26. **窗口外只读**：过了可写窗口的复盘不能在面板改（UI 也不再显示入口）；改旧内容只能打开 Markdown 手工编辑，与「历史分片只读」口径一致。

```bash
npm run check          # 语法（两个入口分别 node --check）
npm run test:task      # 任务域定向：core + service + routes（33）
npm run test:idea      # 想法域定向：core + service + routes + tools（27）
npm run test:review    # 复盘域定向：core + service + routes + tools（24）

```

**测试纪律**：默认只跑定向测试；全量最多一次，只在发版前、跨域共享代码改动、数据结构变更或 CI 时跑（改动→测试矩阵与规则见 [05 协作与测试](./05-协作与测试.md)）。自动化测试只用 `os.tmpdir()` 下的临时数据根，不碰真实 `data/`；真实数据操作前先备份。

## 安装与跨机部署

**从 npm（推荐）**：

```sh
dsh plugin --profile <profile> add dsh-task-workbench
```

**从 GitHub / Release tarball**：

```sh
dsh plugin --profile <profile> add github:Zevin-Labs/task-workbench
# 或先下载 Release 里的 tgz，再按本地压缩包安装：
# dsh plugin --profile <profile> add /path/to/dsh-task-workbench-0.5.0.tgz
```

**本地开发**：插件以 `link:` 方式装进 profile，并加入 `dsh.profile.bundles`：

- `~/.dsh/profiles/<profile>/package.json` → `"dsh-task-workbench": "link:/absolute/path/to/task-workbench"`
- `~/.dsh/profiles/<profile>/node_modules/dsh-task-workbench` → 指向本仓的软链
- 改 host 代码后：在插件页把「任务工作台」组件关/开一次即可热重载；重启 App 后也会加载新代码。
- 改 client 代码后：刷新页面（client bundle 由 DSH HMR 轮询热替换）。

**换机 / 目标机没有仓库**：

1. clone 本仓到固定路径（如 `~/Apps/task-workbench`）。
2. DSH 版本需在 `engines.dsh` 范围内（`>=0.2.2-rc.1 <0.3.0`），否则安装前直接报 `incompatible-version`。
3. 侧栏「插件」→ 添加插件 → 填仓库**绝对路径** → 安装；首次打开「任务工作台」按提示初始化。
4. 数据默认建在 `$DSH_HOME/task-workbench/data`，**两台机器不共享**；同步时拷 `data/任务清单/`、`data/想法池/`、`data/复盘/` 与 `data/备份/`。

目标机没有仓库时：下载 [Release](https://github.com/Zevin-Labs/task-workbench/releases) 里的预构建 tgz，或 `npm run pack` 自己打一个，插件页填 tgz 绝对路径安装。

## 已知限制（当前版本有意为之）

- 外部改动检测用 **5 秒轮询**（不是 `fs.watch` / SSE）；手动点「刷新」可立即重载。
- **不做 Dock 数字徽章**；入口固定在侧栏。
- 只加载/展示**当月任务分片**；历史分片只读，不提供跨月浏览。
- 跨周期只支持一个连续区间；不做重复规则、提醒、子任务。
- 想法池**单文件长期增长**，不做归档/容量上限/自动清理；「已放置 N 天」只是展示，不自动改状态、不提醒。
- 想法**不做「转任务」**，没有跨模块关联与自动回写。
- 复盘**没有历史浏览 tab**：历史复盘靠打开 `data/复盘/*.md` 查看；过了可写窗口不能在面板里改。
- 复盘**不做提醒推送**；块只在窗口内出现，不写也不会追着提醒（当周/当月过去即不再显示）。
- 复盘**不累积补写**：周复盘只提示「上一个自然周」、月复盘只有次月 1–3 日可补；更早的周期不再出现入口。
- 复盘材料跨月时只读合并相邻月份分片；某分片损坏时材料带 warning 并可能不完整（不静默降级）。
- 单进程、单用户假设；不处理多窗口同时写（写入前 `baseHash` 冲突会拒绝覆盖）。
- 客户端文案暂为中文硬编码，未接 DSH locale（单用户）。
- 当前 UI 用 `zoom: 1.5` 整体放大（先保证字号可读）；排版/美观阶段再改成正式的字号体系，窄窗口下本周视图可能出现横向滚动。

## 下一步

2. 按问题小步改：改完只跑对应域的定向测试；本地提交，**攒一批再发版**（发版见 [04](./04-发布与更新.md)）。
3. 稳定后再考虑：复盘历史 tab、复盘统计、想法 → 任务转化、看板视图、提醒、重复任务、跨月浏览——都**不在当前版本**。
