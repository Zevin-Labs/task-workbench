# 文档索引 · 当前架构

> 当前已发布版本为 0.6.1（2026-11-08），以数据根内的 workbench.sqlite 作为唯一真源。V3.0 的产品功能与日期/权限口径继续有效；0.5.0 使用 Markdown，是历史版本。
> 当前 SQLite 版本使用 Node 内置 node:sqlite。初始化创建空库，不导入旧版 Markdown。旧版测试数据已私下归档，不进入仓库与本机路径文档。

## 现在能做什么

**任务**：今日、本周、任务总表；当天任务或连续日期的跨周期任务；可选时间、四象限优先级与多行详情；创建、编辑、完成/撤销、删除。本周页把跨周期任务按轨道贯穿画进 7 个日卡（线从开始日连到截止卡、卡落在截止日），当日任务用底色表达优先级、日卡内只显示任务名；底部有本周/本月概览（三段环形完成率 + 数字）和可翻月的只读月历（点日期查看当天任务，可进编辑或当天新建）。跨月任务保留为同一条数据库记录；过月已完成任务只读。

**想法池**：列表、筛选、搜索；四种状态、三档成熟度、多行描述和可选分类。AI 可读、新建、编辑内容与删除；状态只能由人更改。

**复盘**：日、周、月；窗口内提交、编辑、清空；周/月块显示相关材料；AI 只读。今日页复盘区提供简单的周期回查入口，历史正文只读。

## 当前架构

- 数据位置：默认 DSH_HOME/task-workbench/data/workbench.sqlite；settings.json 可覆盖 dataRoot。数据库与插件安装目录分离。
- 五张表：tasks、ideas、reviews、write_log、meta。meta 保存 schema 版本及领域版本；不另存 ID 序号、初始化标记或审计日志文件。
- Host 用 Node 内置 node:sqlite；短事务在同一提交中写业务变更、审计与域版本。UI 与 AI 都经领域 Service 访问同一个数据库。
- 删除任务、删除想法、清空复盘前会创建并校验 SQLite 快照。backupRetentionDays 保持默认 7 天，可设 1–90 天。
- 任务、想法使用稳定序号 ID（T-1、I-1）；复盘由类型与周期键标识。
- AI 共 14 个工具：任务 7 个、想法 5 个、复盘只读 2 个。任务完成/撤销、想法状态与复盘正文仍只由人操作。

首次初始化得到空数据库；不扫描、不导入旧版 Markdown，也不迁移历史文件。要开始使用时，在工作台点击初始化。

## 长远扩展边界

未来时间块匹配、人与 AI 协作可以沿用稳定业务 ID 和领域 Service 入口；当前不预建字段/表，也不开发时间管理、AI 认领或审核流程。保持单机单用户设计，不引入同步、多用户、后台服务或通用框架。

## 安装与开发

要求 Node >=24，DSH 版本范围见 package.json。可从 npm 或 GitHub 安装：

- npm：dsh plugin --profile <profile> add dsh-task-workbench
- GitHub：dsh plugin --profile <profile> add github:Zevin-Labs/task-workbench

源码开发运行 npm run check 与对应域的定向测试。改 Host 后需重启 DSH（插件重载不会重新加载 host 模块）；改 Client 后刷新页面即可。发版步骤见 [04 发布与更新](./04-发布与更新.md)。

## 已知限制

- 单机、单用户、单 Host 进程；不做多用户同步或云备份。
- 任务总表不提供按月份浏览历史任务；本周页月历只做只读翻月、按日期查看当天任务（可进编辑）与当天新建入口，不提供整月历史任务列表。默认任务列表显示全部未完成任务及本月已完成任务。
- 复盘历史回查是轻量只读入口，不做独立历史 tab、统计图表或更早周期补写。
- 想法池不自动归档；不做想法转任务、看板、提醒或容量管理。
- 无重复任务、日历时间块、系统推送、AI 认领/执行/验收能力。
- 客户端文案暂为中文；不接 DSH locale。
